# Slimeworks — 3D incremental MVP

Небольшая first-person игра на C и raylib: добывайте слизь-руду, стройте станции и открывайте вторую зону фабрики.

Мир состоит из большой нижней сервисной равнины и шести плоских районов на разных высотах. Районы соединены широкими проходимыми склонами: центральная фабрика, ранчо слизней, небесная лаборатория, кислотный завод, кристальная площадка и оранжевый испытательный полигон.

## Запуск

```sh
make
./main
```

Нужен установленный raylib, доступный через `pkg-config`.

## Управление

* `WASD`, `Shift`, `Space`, мышь — движение, бег, прыжок и обзор.
* `E` (удерживать) — добыть жилу; в режиме строительства — поставить станцию.
* `B` — режим строительства; `1–3` — насос, переработчик, усилитель.
* `U` — улучшить ближайшую станцию до уровня 2 за слизь.
* `O` рядом с воротами — открыть вторую зону за 55 слизи.
* `F5` — сохранить, `F9` — загрузить ручное сохранение.
* `Esc` — отпустить/захватить мышь.

Подробное пошаговое руководство: [HOW_TO_PLAY.md](HOW_TO_PLAY.md).

Developer console открывается `F4`; команды и навигация описаны в руководстве.

## Петля MVP

1. Добывайте зелёную слизь-руду и ставьте насосы.
2. Поставьте переработчик: он превращает зелёную руду в слизь.
3. Усилитель повышает скорость станций рядом с ним; улучшение даёт второй уровень.
4. Откройте вторую площадку, добывайте кислотную/кристальную руду и ловите редкого кристального слизня.

## Архитектура

* `src/core/update_loop` — маленький реестр систем с единым callback-методом `Update(context, dt)`; `game.c` только собирает и запускает их.
* `src/core` — композиция систем и агрегированное состояние сессии.
* `src/economy` — ресурсы и операции с валютой.
* `src/entities` — жилы ресурсов и добыча.
* `src/build` — станции, стоимость, производство и улучшения.
* `src/gameplay` — действия игрока в мире: строительство, трубы, контракты, сохранение и взаимодействия.
* `src/save` — один локальный ручной слот в `saves/slimeworks.save`.
* `src/ui` — HUD, подсказки и уведомления.
* `src/player/player_state`, `player_input`, `player_motor`, `player_camera`, `player_system` — состояние, ввод, физика, камера и их единый `PlayerSystemUpdate`.
* `src/world` — геометрия уровня и данные спавна.
